AutoCell

Ứng dụng đo kiểm mạng di động (Android/iOS) và bảng điều khiển web theo dõi thiết bị theo thời gian thực.

Ứng dụng di động

  • Đọc thông số mạng 3G / 4G / 5G (RSRP, RSRQ, SINR, PCI, TAC…).
  • Khớp trạm phục vụ từ database cell, hiển thị antenna và lịch sử serving.
  • Bản đồ đo kiểm, lộ trình tín hiệu, xuất KML.
  • Quản lý danh sách cell (thêm / sửa / xóa / import).

Web

  • Bản đồ: vị trí user online, trạm cell, lọc 3G/4G/5G, đo khoảng cách và góc.
  • Serving cell vẽ cánh sóng theo tilt/height; cell khác vẽ hướng azimuth.
  • User: danh sách thiết bị, trạng thái mạng và vị trí.
  • Đăng nhập: Firebase Auth, phân quyền root / admin / support.
